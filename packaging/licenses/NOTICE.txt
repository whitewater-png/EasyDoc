Corresponding source
--------------------
The complete corresponding source is offered from the same place as the
packages: every GitHub release of Leafweaving has these files attached next to
the packages (https://github.com/whitewater-png/Leafweaving/releases), and
SHA256SUMS.txt there covers them:

* leafweaving-<version>-src.tar.gz — Leafweaving itself at the release tag,
  including the build scripts (packaging/) and the exact third-party
  versions that were bundled (packaging/constraints.txt).
* pymupdf-<version>.tar.gz and mupdf-<version>-source.tar.gz — PyMuPDF and
  the MuPDF release it is built from (AGPL-3.0).
* qt-everywhere-src-<version>.tar.xz and
  pyside-setup-everywhere-src-<version>.tar.xz — Qt and Qt for Python /
  Shiboken (LGPL-3.0).
* pikepdf-<version>.tar.gz and certifi-<version>.tar.gz (MPL-2.0).

CPython's source for the bundled interpreter version (see
third-party/CPython/VERSION.txt) is at https://www.python.org/downloads/source/.

All third-party components are used unmodified.  To rebuild a package with
your own versions of these components (including replacing the Qt shared
libraries), follow the build instructions in the README at the release tag
(python packaging/build.py).

On Linux the package relies on the shared libraries of the operating system
(Qt's platform plugins load them at run time; see the README for the package
names) and does not include them.  On Windows the Microsoft Visual C++
runtime libraries required by CPython and Qt are included under Microsoft's
redistribution terms.

Qt (LGPL-3.0): the Qt libraries are shipped as separate shared libraries /
frameworks in the package, so you may replace them with a compatible build of
your own.  The full LGPL-3.0 text is in LGPL-3.0.txt; it incorporates the
GPL-3.0 (GPL-3.0.txt).

Ghostscript is not included.  Leafweaving runs a separately installed
Ghostscript as an external program when one is present.

A complete list of every native library in this package and the component it
belongs to is produced at build time (build/BINARIES.txt) and checked against
the components above.
